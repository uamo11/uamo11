### 👨‍💻 Sobre Mí

Soy **Antony**, desarrollador de software basado en **Venezuela**. Me apasiona crear software rápido, privado y eficiente, desde aplicaciones móviles con interfaces reactivas hasta utilidades que interactúan directamente con la memoria del sistema y el hardware:

- 📱 **Desarrollo Móvil en Android**: Creación de aplicaciones modernas y fluidas usando **Jetpack Compose** y **Material You**, con arquitectura limpia (MVVM) y funcionamiento 100% offline sin rastreadores.
- ⚙️ **Sistemas, Reversing y Bajo Nivel**: Lectura segura de memoria en Android ARM64 (`/proc/PID/mem`, syscalls directas), renderizado nativo con **Vulkan 1.1 + Dear ImGui**, inspección y reversing en Win32 y Android.
- 🤖 **Herramientas de IA y Protocolos MCP**: Construcción de servidores y extensiones basadas en el **Model Context Protocol (MCP)** para integrar LLMs avanzados (Antigravity IDE, Claude, Gemini) con entornos de ejecución locales.
- 🔒 **Privacidad y Criptografía**: Integración de almacenamiento seguro en hardware (Android Keystore, AES-256-GCM), cifrado simétrico y técnicas de esteganografía.
