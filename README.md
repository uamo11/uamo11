## 🥇 Proyecto Principal (#1): [OpenManager](https://github.com/uamo11/OpenManager)

> **Gestor de archivos Dual-Panel & Suite de Ingeniería Inversa Open-Source para Android** — Alternativa moderna, gratuita y sin VIP ni anuncios a MT Manager (**GPLv3**).

    <td valign="top">
      <p>
        <a href="https://uamo11.github.io/OpenManager/"><strong>🌐 Web Oficial</strong></a> &nbsp;·&nbsp;

        Construido con <strong>Kotlin + Java + C/C++ (CMake/JNI)</strong> para móviles, tablets, <strong>Android TV (Leanback)</strong> y <strong>Samsung DeX</strong> (Android 6.0–16 · API 23–36 · APK de ~30 MB · consumo real de ~125–145 MB RAM PSS).

      <ul>
        <li><strong>Ingeniería Inversa &amp; APK Modding:</strong> Decompilador <strong>JADX 1.4.7</strong> integrado, editor <strong>Smali/DEX</strong> (<code>smali-dexlib2</code> / <code>baksmali</code>), editor <code>.arsc</code> &amp; AXML binario, editor <strong>HEX</strong>, <strong>AntiSplit</strong> y autofirma con <code>apksig</code>.</li>
        <li><strong>Visores &amp; Utilidades Avanzadas:</strong> Visor <strong>SQLite</strong>, <strong>PDF</strong>, <strong>DOCX</strong>, imágenes HD con zoom subsampling, SVG/GIF, buscador de archivos duplicados, búsqueda de texto dentro de archivos, soporte <code>libarchive</code> y 5 hashes (<code>CRC32</code>, <code>MD5</code>, <code>SHA-1</code>, <code>SHA-256</code>, <code>SHA-512</code>).</li>
        <li><strong>Red Segura &amp; Privilegios:</strong> Servidor FTP integrado (<code>mina-core</code> parcheado frente a <code>CVE-2024-52046</code>), clientes <strong>SFTP</strong> (<code>SSHJ</code>), <strong>SMB LAN</strong> (<code>jCIFS-NG</code> / <code>SMBJ</code>) y <strong>WebDAV</strong>, elevación con <strong>Shizuku 13.1.5</strong>, <strong>Root (<code>libsu</code>)</strong> y soporte <strong>SELinux</strong>.</li>
      </ul>

## 👨‍💻 Sobre Mí &amp; Stack Tecnológico

Soy **Antony**, desarrollador de software desde **Venezuela 🇻🇪**. Me enfoco en software rápido, transparente y respetuoso con la privacidad:

- 📱 **Android Nativo &amp; Multi-formato:** Apps en **Kotlin**, **Jetpack Compose**, **Material You** y **Android Views** adaptadas a teléfonos, tablets, **Android TV (Leanback)**, **Samsung DeX** y soporte **RTL**.
- ⚙️ **C/C++ (JNI) &amp; Bajo Nivel:** Integración de librerías nativas mediante **CMake / NDK** (`libarchive`, `libselinux`), manejo eficiente de memoria y herramientas de análisis/ingeniería inversa de APKs (**JADX**, **DEX/Smali**, **ARSC/AXML**).
- 🔒 **Privacidad, Redes &amp; Criptografía:** Almacenamiento cifrado en **Android Keystore (AES-256-GCM)**, hashing múltiple y protocolos seguros (**FTP** hardened, **SFTP**, **SMB**, **WebDAV**) sin rastreadores ni telemetría.
